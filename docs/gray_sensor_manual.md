# 第五代数字量智能灰度传感器 — 关键信息摘要

> 来源：`第五代数字量智能灰度传感器说明书.pdf` (V5.0, 2023-06-06)

## 技术参数

| 参数 | 值 |
|------|-----|
| 供电 | 3.3V ~ 5.5V（推荐 5V） |
| 电流 (16路) | ~173mA |
| 检测距离 | 10mm ~ 50mm（有阳光需遮光） |
| 数据刷新率 (16路数字量) | **1.5KHz** |
| 模拟值范围 | 0 ~ 4095 (12-bit) |
| 中线参考值 (16路) | 8500 |
| 适用平台 | Arduino, 51, STM32, K60, 树莓派 |

## 输出数据类型

| 类型 | 内容 |
|------|------|
| 数字量 | 每路 1 bit，0/1 表示黑白 |
| 偏移量 | 线相对传感器中心的位置，含压线数量和出线方向 |
| 模拟量 | 每路 12-bit ADC 原始值 |
| 全输出 | 以上三种同时输出 |

## 通信方式

传感器支持三种接口（可同时使用）：
- **UART**（默认，本项目使用）
- 数字口并行输出
- IIC

## 串口通信协议 (5.1)

**格式**：115200 bps（默认），8N1

**通信模式**：主机发送命令 → 传感器应答

---

### 表一：数字量数据（16路）

```
主机发: 0x57  ID
传感器回: 0x75  Data0  Data1  0x03
```

| 字节 | 内容 |
|------|------|
| `0x57` | 起始信号（'W' 的 ASCII） |
| `ID` | 传感器编号（默认 0x01） |
| `0x75` | 帧头 |
| `Data0` | bit0~7 → 通道 1~8（低位在前），1=压线 |
| `Data1` | bit0~7 → 通道 9~16 |
| `0x03` | 帧尾（16/12 路为 0x03，8/7/5/3 路为 0x02） |

一帧共 **6 字节**（16路），8 路为 5 字节。

---

### 表二：偏移量数据

```
主机发: 0x57  ID
传感器回: 0x75  Data0  Data1(偏移高8位)  Data2(偏移低8位)  0x04
```

| Data0 位 | 含义 |
|----------|------|
| bit0~4 | 压线数量 (0~16) |
| bit5 | 偏移正负 (1=正/右偏, 0=负/左偏) |
| bit6 | 出线检测 (1=右出线, 0=左出线) |

偏移值为 0 表示线在传感器正中；靠左为负，靠右为正。

一帧共 **7 字节**。

---

### 表三：模拟量数据（16路）

每通道 2 字节（高 8 位在前，低 8 位在后），最大值 4095 (0x0FFF)。

```
主机发: 0x57  ID
传感器回: 0x75  Data0~31  帧尾(0x21)
```

- Data0/1 → 通道 1，Data2/3 → 通道 2，...，Data30/31 → 通道 16
- 帧尾 16 路为 `0x21`，8 路为 `0x11`
- 16 路一帧共 **36 字节**

---

### 表四：全部数据输出（16路）

数字量 + 偏移量 + 模拟量合并一帧。

```
传感器回: 0x75  Data0(数字量ch1-8)  Data1(数字量ch9-16)  Data2(位置)  Data3~4(偏移)  Data5~36(模拟量)  帧尾(0x26)
```

16 路一帧共 **41 字节**，帧尾 `0x26`。

---

## IIC 通信协议 (5.3)

IIC 时钟 ≤ 250KHz，模块地址为 7-bit。默认地址 `0x01`。

### Slave Address 构成

| Bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-----|---|---|---|---|---|---|---|---|
| 含义 | address[6:0] | R/W |

- 写操作：`(addr << 1) | 0`，如默认地址 `0x01` → 写地址 `0x02`
- 读操作：`(addr << 1) | 1`，如默认地址 `0x01` → 读地址 `0x03`

注意：SDA/SCL 需加 4.7K 或 10K 上拉电阻（除非单片机有上拉输入模式）。

### 模块寄存器地址

| 寄存器 | 数据内容 |
|--------|---------|
| `0x10` | 模块地址。1 字节：7 位地址 + 1 位读写标志位，取值 0x00~0x7F |
| `0xA0` | **数字量数据**。3/5/7/8 路为 1 字节，12/16 路为 2 字节 |
| `0xA1` | **偏移量数据**。3 字节：位置数据 + 偏移高 8 位 + 偏移低 8 位 |
| `0xA2` | **模拟量数据**。3 路 6B / 5 路 10B / 7 路 14B / 8 路 16B / 12 路 24B / 16 路 32B。每 2 字节为一个 16 位模拟值（高 8 位在前） |

### 设置模块地址 — 写操作 (5.3.1)

写操作流程：Start → Slave address(W) → ACK → 寄存器地址(0x10) → ACK → 新地址(7-bit) → ACK → Stop

```
Start | (0x01<<1) | ACK | 0x10 | ACK | 新地址 | ACK | Stop
```

新地址自动保存，上电重启生效。

### 获取灰度数据 — 读操作 (5.3.2)

读操作使用伪写+读的复合格式：

1. 主机发 Start → Slave address(W) → 寄存器地址 → ACK
2. 主机发 Restart → Slave address(R) → ACK
3. 从机发数据 → NACK → Stop

**读取数字量**（传感器需设为数字量输出）：

```
Start | 0x01<<1 | ACK | 0xA0 | ACK | Stop
Start | (0x01<<1)+1 | ACK | 数据 | NACK | Stop
```

**读取偏移量**（传感器需设为偏移量输出）：

```
Start | 0x01<<1 | ACK | 0xA1 | ACK | Stop
Start | (0x01<<1)+1 | ACK | 3字节数据 | NACK | Stop
```

**读取模拟量**（传感器需设为模拟量输出）：

```
Start | 0x01<<1 | ACK | 0xA2 | ACK | Stop
Start | (0x01<<1)+1 | ACK | N字节数据 | NACK | Stop
```

> IIC 读取的数据类型由传感器当前输出模式决定，需通过串口命令提前设置（参照设置命令表五）。

## 数字口并行输出 (5.2)

数字口直连单片机 IO（输入模式），每路输出高低电平：
- 跳线 3.3V → 高电平为 3.3V（默认）
- 跳线 5V → 高电平为 5V

---

## 设置命令 (5.1.2 表五)

功能码：`0x4C`（'L' 的 ASCII）

格式：`0x4C  ID  寄存器地址  数据`

| 寄存器 | 功能 | 数据 |
|--------|------|------|
| `0x01` | 输出类型 | 0=数字量, 1=偏移量, 2=模拟量, 3=全输出 |
| `0x02` | 暗色电平 | 0=低电平, 1=高电平 |
| `0x03` | 中线参考值 | 0~0xFF（16路理论值 8500） |
| `0x04` | ID 设置 | 0~0x7F（默认 0x01，重启生效） |
| `0x05` | 波特率 | 0=115200, 1=57600, ... 6=9600 |
| `0x06` | 颜色采集 | 0=采背景, 1=采线色, 2=采居中值, 3=自动 |
| `0x07` | 巡线模式 | 0=亮灯, 1=灭灯, 2=自适应 |
| `0x0B` | 复位 | 发 `0x01` 恢复出厂设置 |

**示例**：设置偏移量输出 → 发送 HEX `4C 00 01 01`

---

## 出线检测逻辑

- **左出线**：线从传感器左侧脱离 → Data0 bit6 = 0
- **右出线**：线从传感器右侧脱离 → Data0 bit6 = 1
- **Out**：线不在传感器下方
- **Line**：线在传感器下方

注意线不可过细，否则在两灯之间时检测不到。

---

## 循迹技巧 (第七章)

| 场景 | 方法 |
|------|------|
| 直线/圆形 | 标准循线即可 |
| 弧形弯道 | 慢速用直线方法，快速需激光提前检测降速 |
| T/十字路口 | 当 ≥4 个灯同时在黑线上即判定到达路口 |
| 不规则路口 | 用最左或最右传感器单独检测 |

---

## 调试 (第六章)

- 按键采集：长按 K1 进调试模式 → 放背景色上按 K2 → 平移传感器来回过线 → 5 秒自动完成
- 灵敏度自动调节，无需电位器
- 恢复出厂：同时按 K1+K2 约 4 秒，或串口发 HEX `4C 00 0B 01`

## 电源保护

- 自带反接保护
- 钽电容滤波
- 宽电压 3.3V ~ 5V
