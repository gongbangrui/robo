# LED Status & Error Codes

RGB LED 位于 TIM5 三路 PWM（Red=CH3, Green=CH2, Blue=CH1）。

## 状态总览

| 阶段 | 颜色效果 | 含义 |
|------|----------|------|
| 启动（0-5s） | 彩虹循环渐变 | 系统初始化中 |
| 正常运行 | 绿色呼吸灯（缓慢亮灭） | 所有设备在线，正常巡线 |
| 故障 | 颜色闪烁 | 见下表 |

## 故障颜色编码

| 颜色 | 闪烁 | 故障源 |
|------|------|--------|
| 红色快速 | 120ms 亮 / 180ms 灭 | **任意底盘电机离线**（CAN1 0x201-0x204） |
| 黄色 | 250ms 亮 / 350ms 灭 | **IMU 传感器错误**（BMI088 陀螺仪/加速度计，或 IST8310 磁力计） |
| 蓝色 | 250ms 亮 / 350ms 灭 | **灰度传感器离线**（USART1 DMA 空闲中断未触发） |
| 白色 | 250ms 亮 / 350ms 灭 | **多个子系统同时故障**（上述组合） |

## 故障优先级

当多个故障同时存在时，按以下优先级显示：

1. **多个子系统** — 白色（最高优先级，表示严重）
2. **单一百度故障** — 对应单一颜色
3. 正常 → 绿色呼吸

逻辑：出现任何故障立即切入闪烁模式，所有故障恢复后自动回到绿色呼吸灯。

## 新增故障类型

如需增加新的设备故障指示，修改 `led_flow_task.c` 中的 `led_error_mask()` 函数：

```c
/* 新增灰度传感器故障 → 分配给 bit 3 */
if (toe_is_error(NEW_SENSOR_TOE))
    m |= 8;
```

然后在 `PHASE_ERROR` 的 switch 中添加对应颜色：

```c
else if (err == 8) { color = C_XXX; }
```
